# Иллюстрации в VIDEO

Выберите главу на таймлайне и нажмите **＋ Визуал** рядом с «Глава» и
«Сцена», либо **＋ Иллюстрация** в инспекторе. Выберите одну или несколько
картинок из «Материалов». Здесь же можно импортировать новые изображения
в существующую библиотеку. Добавление картинки не перезапускает озвучку.

На дорожке **Визуальные вставки** клип можно двигать внутри своей главы,
подрезать за левый край и растягивать за правый. В инспекторе доступны
изображение, глава, момент появления от начала главы, длительность и
переход 0,5–1 с. Можно вводить секунды либо `чч:мм:сс.мс`.
Кнопка удаления и Delete/Backspace убирают только выбранную вставку.

**Авторасставить визуалы** в инспекторе пересчитывает выбранную главу,
а одноимённая кнопка таймлайна — главы всего проекта. Используются уже
добавленные вставки; если их нет — назначенное изображение главы.
Для длинной главы одна иллюстрация начинается через 30 с и длится 180 с.
Несколько картинок получают отдельные интервалы с промежутками обычной
сцены. В коротких главах время сокращается пропорционально. При добавлении
новых картинок существующие ручные настройки не меняются: новые клипы
размещаются после последнего. Если там нет места, редактор сообщает об этом.

Иллюстрация вписывается целиком через contain. Свободное пространство
заполняется увеличенной, размытой и затемнённой копией картинки. QR остаётся
на своём месте; прогресс, текущее/полное время и включённый визуализатор
рисуются поверх. Название главы остаётся небольшой плашкой. После вставки
возвращается обычная сцена с текстом. Дорожка «Видео / фон» самостоятельна.

## Формат и границы

Вставки сохраняются в главе, в JSON настроек существующей видео-редакции
SQLite и в совместимом `editor-project.json`. Исходные файлы хранятся как
обычные материалы. Отсутствующее `visualInserts` трактуется как `[]`.

```json
{
  "id": "chapter-1",
  "start_seconds": 300,
  "end_seconds": 900,
  "visualInserts": [
    {
      "id": "visual-1",
      "type": "image",
      "assetId": "existing-material-id",
      "startTime": 30,
      "duration": 180,
      "transition": "crossfade",
      "transitionDuration": 0.75
    }
  ]
}
```

В этом примере вставка показывается на времени книги 330–510 с. Переходы
входят в указанную длительность: fade-in в начале интервала, fade-out
перед его концом. `transition: "none"` переключает сцену сразу.

Интервал полуоткрытый: `[начало, конец)`. Конец ограничен следующей главой.
При ручном пересечении приоритет получает более ранняя вставка; начало
следующей откладывается до её окончания, без переноса собственного конца.
Полностью перекрытая вставка остаётся в данных и доступна в инспекторе.
Сокращение главы также не уничтожает исходные тайминги: не поместившуюся
вставку можно исправить в списке инспектора или вернуть, удлинив главу.
Перенос начала главы автоматически переносит её визуалы вместе с ней.

## Общая логика preview и export

`bookender/visual_inserts.py` компилирует исходные данные в план сцены:
режим, абсолютные границы, ключевые кадры прозрачности и геометрию картинки.
`POST /api/scene-plan` отдаёт этот план для несохранённых настроек редактора.
Во время воспроизведения и перемотки Vue только интерполирует ключевые
кадры (`ui/src/scenePlan.js`), без запросов на каждый кадр или CSS-таймеров.
Для расчёта новых/изменённых планов нужен работающий локальный медиадвижок.

Экспорт заново вызывает тот же компилятор. `bookender/visual_render.py`
готовит сменяемое содержимое и переводит ключевые кадры в FFmpeg alpha fades.
`suviren_q.py` отделяет содержимое панели от постоянного прозрачного слоя
QR/шкалы/общей длительности, затем добавляет живой спектр и текущий таймкод.
Озвучка собирается существующим единым master mux, независимо от вставок.
Проекты без вставок используют прежний путь рендера.

Для нового содержимого (`comic`, `quote`, `video`) предусмотрены реестры
`CONTENT_MODES`, `CONTENT_RENDERERS`, `VISUAL_CONTENT_COMPONENTS`: добавляется
адаптер содержимого, а расписание и постоянные слои остаются общими.
Сейчас реализованы изображения; комикс можно собрать последовательностью
обычных вставок с отдельными картинками.

## Проверки

```powershell
.venv/Scripts/python.exe -m unittest tests.test_visual_inserts -v
npm --prefix ui test
npm --prefix ui run test:e2e
npm --prefix ui run build
```

Тесты проверяют старые проекты, одну/несколько вставок, короткие главы,
границы, пересечения, произвольную перемотку, общий план Python/JavaScript,
сохранение в SQLite/JSON и повторное открытие. Реальный FFmpeg-тест проверяет
оба перехода по пикселям кадров, постоянный QR, рендер из середины вставки,
полный конвейер экспорта и непрерывную длительность итогового AAC.
