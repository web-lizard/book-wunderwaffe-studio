# Book Wunderwaffe Pocket

`Book Wunderwaffe Pocket` — урезанная Android-редакция Book Wunderwaffe Studio для
написания книг, системной озвучки и прослушивания готового цельного аудио. Приложение
local-first: книги, главы, задания и WAV остаются на телефоне. Собственный сервер и
аккаунт не нужны.

## Что входит в v0.1.0

- несколько книг и глав с постоянными UUID и автосохранением;
- удобный редактор с явными командами «Вставить», «Копировать всё» и «Очистить»;
- выбор установленного системного голоса Android, темпа и высоты тона;
- озвучка главы или всей книги одним WAV, даже для текста длиннее лимита TTS;
- foreground-service: озвучка продолжается при свёрнутом приложении и выключенном
  экране, а уведомление показывает этап, процент и кнопку остановки;
- восстановление прогресса из SQLite и контрольные точки между фрагментами;
- скрытая техническая консоль с временем, движком, форматом и номером фрагмента;
- встроенный плеер с waveform-индикатором, перемоткой, ±15 сек и скоростью;
- сохранение WAV через системное окно Android и отправка в другое приложение;
- локальная эвристика названия: название книги, первая содержательная строка или
  несколько значимых слов — без облачного ИИ;
- импорт и экспорт версионированного пакета `.bwlbook` для будущего обмена с desktop.

## Установка APK

Готовая debug-сборка после выполнения скрипта находится в
`android/releases/book-wunderwaffe-pocket-v0.1.0-debug.apk`. Она подписана стандартным
отладочным ключом Android и устанавливается на Android 8.0 (API 26) и новее. Для
ручной установки потребуется разрешить установку из используемого файлового
менеджера.

При первом запуске:

1. Разрешите уведомления — тогда длительный прогресс будет виден в шторке. При
   отказе Android всё равно показывает foreground-задачу в диспетчере активных
   приложений.
2. Откройте «Аудио» и выберите голос. Голоса с пометкой «нужна сеть» могут не
   работать офлайн; автономные голосовые данные ставятся в настройках системного
   синтезатора речи.
3. Создайте книгу и главу, вставьте текст, затем нажмите «Озвучить главу» или
   «Озвучить всю книгу».
4. Готовый файл появится в плеере. «Сохранить в телефон» открывает Storage Access
   Framework, поэтому разрешение на весь накопитель приложению не требуется.

## Сборка

Требуются JDK 17+, Android SDK Platform 35 и Build Tools 35.0.0. На Windows:

```powershell
cd android
.\build-apk.ps1
```

Или напрямую:

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

Проект намеренно использует Java и только Android platform APIs: нет AndroidX,
Compose, WebView, Python, FFmpeg или обязательных сетевых зависимостей во время
работы приложения.

## Ограничения первой версии

- Качество и доступность русского голоса зависят от TTS-движка на конкретном
  телефоне. Приложение не копирует облачный Edge TTS desktop-версии.
- WAV без потерь прост и надёжен для склейки, но занимает примерно 170 МБ на час
  при 24 кГц, mono, 16 bit. Классический RIFF ограничен размером около 4 ГиБ;
  приложение проверяет предел и не публикует повреждённый файл.
- В Android 15 foreground-задачи типа `dataSync` имеют системный суточный лимит.
  Контрольные точки позволяют продолжить прерванную работу, однако очень большие
  многотомники лучше озвучивать отдельными книгами.
- Автоматической синхронизации с ноутбуком пока нет. `.bwlbook` уже фиксирует
  стабильные UUID, revisions, hashes и относительные пути; поверх него можно
  добавить LAN/QR pairing или облачный `SyncGateway`, не меняя модель данных.

## Приватность

В manifest нет разрешения `INTERNET`. Текст обрабатывается выбранным системным
TTS-движком; если выбран сетевой голос, политика и передача текста определяются
установленным на телефоне движком. Пакеты и аудио покидают приложение только после
явного выбора «Сохранить», «Поделиться» или «Экспорт `.bwlbook`».
