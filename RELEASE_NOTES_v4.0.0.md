# Book Wunderwaffe Studio 4.0.0

Версия 4.0 рассчитана на большие иллюстрированные книги и сотни кадров на таймлайне.

## Главное

- полноразмерным загружается только текущий кадр;
- таймлайн и инспектор используют кэшированные WebP-миниатюры;
- невидимые клипы не создают изображения и ограничиваются видимой областью;
- материалы индексируются один раз, активная сцена находится двоичным поиском;
- проект не перезаписывается целиком при обычном открытии;
- сохранена полная совместимость с проектами и базой данных версии 3.0.

На тестовом проекте «Торговец Солнцем» объём изображений при входе в видеоредактор уменьшился примерно с 523 МБ до 0,47 МБ.
